Problem 6: Best imputation strategy per column

Module 3 · Missing data handling

Column Recommended strategy Justification (যুক্তি)
Income
15% missing, skewed right		 Median (train-only) or log-transform + median Mean ভুলভাবে উচ্চ outlier-এর দিকে টেনে নেয়। Median robust। খুব skewed হলে log(1+x) করে median নিলে distribution ভালো থাকে।
Rating
8% missing, normal		 Mean (train-only) Bell-shaped ডেটায় mean ≈ center; কম missing হওয়ায় mean imputation সাধারণত যথেষ্ট।
City
5% missing, 50 categories, one dominates		 Mode (most frequent) + optional missing indicator High cardinality-তে random category ঝুঁকিপূর্ণ। Dominant class (≈40%) mode হিসেবে নিরাপদ baseline। Indicator দিলে “City ছিল না” তথ্য রাখা যায়।
Diagnosis
22% missing, 3 balanced classes		 Constant = "Missing" + missing indicator Mode impute করলে ভুল class bias হতে পারে। আলাদা “Missing” level + binary flag মিসিং প্যাটার্ন মডেলে রাখে।
Cabin
68% missing, many categories		 Drop column অথবা constant "Unknown" + indicator ৬৮% missing মানে বেশিরভাগ row-এ আসল তথ্য নেই — impute করলে noise বাড়ে। প্রায়ই column drop বা একটিমাত্র “Unknown” + indicator সবচেয়ে ভালো।
সাধারণ নিয়ম: সব imputation train set-এ fit, test-এ শুধু transform — data leakage এড়াতে। Numerical → median (skewed) বা mean (symmetric); categorical → mode বা dedicated “Missing”; খুব বেশি missing → drop বা indicator।
